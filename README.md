# Personal Website - vuongho.me

A minimalist, mobile-first digital business card built with Vite, Preact, and TailwindCSS, hosted on Firebase Hosting.

## Features

- 🎨 Dark mode aesthetic with subtle CSS animations
- 📱 Mobile-first, responsive design
- 💳 Interactive card flip animation
- 🔄 Easy to customize through a single JSON file
- ⚡ Prerendered HTML with inlined CSS, self-hosted font, and AVIF/WebP images — ~16 KB of gzipped JS that isn't on the critical path

## Getting Started

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # type-check, build, and prerender into dist/
npm run preview   # serve dist/ locally
```

## Deploying

Pushing to `main` deploys automatically via GitHub Actions (`.github/workflows/deploy.yml`). Pull requests get a
type-check and build. The workflow authenticates to the `vuonghome` Firebase project with Workload Identity Federation
(service account `github-deployer@vuonghome.iam.gserviceaccount.com`), so no keys are stored in GitHub.

To deploy manually from your machine:

```bash
npx firebase login   # once
npm run deploy
```

## Customization

All personal information is stored in `src/config/personal-info.json`.

Images live in `images-src/` as originals. After adding or changing one, run `npm run images` to regenerate the
resized AVIF/WebP/JPEG versions in `public/images/`. `profileImage` in the JSON is a base path
(`/images/avatar` → `avatar-400.avif`, `avatar-800.webp`, …); institution icons point at the generated `.webp` files.

## How it's fast

- `scripts/prerender.js` renders the app to static HTML at build time and inlines the stylesheet, so the first
  response paints the full card with no extra round-trips; Preact then hydrates it for interactivity.
- Space Grotesk is self-hosted (latin subset, variable weight) and preloaded.
- Hashed assets are served with `immutable` year-long caching (`firebase.json`).

## Project Structure

```
  ├── types/
  ├── App.tsx
  ├── main.tsx            # Client entry (hydrates the prerendered HTML)
  └── entry-server.tsx    # Prerender entry
```
